The following pages are compressed transcripts from video tutorials by [David Healey](https://www.youtube.com/@DavidHealey), an experienced HISE developer and educator. Each video has been processed into a concise, actionable recipe that preserves the key knowledge, best practices, and code examples while removing the filler inherent to video content.

These recipes are not a replacement for the original videos — they are a searchable, skimmable reference. Where applicable, code blocks are provided as copy-pasteable HiseScript. Each section links back to the exact timestamp in the original video via YouTube deep links.
